# Class Notes issues: one file per email
The sender takes the next `NN-slug.md` in file-name order every Wednesday and Sunday, 7:00 AM Eastern (MailCheap). Skip this README: it is not an issue.
Front matter: `topic` (1 to 2 words), `cat` (a cat pose: laugh, lift, think, calendar, write...), `tone` (rosy, plum, blush or sky), `subject` (2 to 7 words, under 60 characters), `preview` (one number or promise, under 110 characters), `slug` (kebab-case, unique, equal to the file name without `NN-`: the issue's web address).
Body order: `Hi {{first_name|there}},`, a hook, the idea with a source mark like [1] after each number, **Try it today: name**, **A question I hear in clinic** (answered in 3 to 5 lines), **See a doctor if** (only when the topic has warning signs).
Then one main link (the letter, the resource or the fiber guide), the app line once, `Dana`, and **Sources** as a numbered list, copied exactly from the letter or the resource. The email does not show the list: it links to the issue's page, https://www.healthclass.app/letters/<slug>, which shows every sent issue with its sources (the sender and the site both read this file).
Letter issues end with "Read the full letter, with the sketch:" and the letter's link at https://www.healthclass.app/letters/<slug>.
Rules: body under 350 words, sentences under 30 words, no em or en dashes, numbers over adjectives, simple words, Dana's first person.
Bold lines, never # headings. No header and no footer: MailCheap adds the author, the unsubscribe link and the postal address.
Facts come only from content/articles, content/resources and the fiber guide (lib/fiber.ts). No prices, no free trial.
Before an issue ships: count the words, grep for em and en dashes, check sentence length and subject length.
